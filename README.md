# Venom Cooperation Lab

Planowane opcjonalne laboratorium badania współpracy i samoorganizacji sesji modeli AI w Venomie.

Repozytorium jest na etapie planowania. Nie zawiera działającego modułu ani modeli. Pierwszy zakres to kwalifikacja jednego nowego modelu, dwie odrębne sesje tych samych wag i widoczny przebieg eksperymentu.
